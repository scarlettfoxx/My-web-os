# My-web-os
A simple web-based operating system made with HTML, CSS, and JavaScript.
## About
This is a fake desktop that runs in the browser.It has icons, a clock, and a few working apps.
## Features
-Desktop with icons
-Working clock
-Files Window
-Browser Window (fake search)
-Settings Window
-Calculator app
-Custom Wallpaper
## How to use
1. Click on any icon to open an app
2. Click the x button to close any window
3. Use the calculator for basic math

## Built with
-HTML
-CSS
-JavaScipt
